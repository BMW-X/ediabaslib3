API reference

This page lists the public members that host applications use. All types live in the EdiabasLib namespace. Nullable reference types are disabled in the library, so signatures don't show which parameters accept null.

EdiabasNet

public partial class EdiabasNet : IDisposable

The interpreter. Create one instance per diagnostic session. An instance runs one job at a time.

Constructors

EdiabasNet()
Reads EDIABAS.INI and EdiabasLib.config from the assembly directory.
EdiabasNet(string config, bool isHosted = false)
config is either @<path> to a config file or a key=value;key=value list that overrides file settings. isHosted skips the automatic trace directory setup. See Where settings come from.
void Dispose()
Runs the exit job if required, closes the ECU file, disposes the interface handler, and closes the trace files. Safe to call more than once.

File and job methods

void ResolveSgbdFile(string fileName)
Resolves a .GRP or .PRG name relative to EcuPath and stores the result in SgbdFileName. For a group file, runs the identification job against the vehicle. Throws ArgumentOutOfRangeException when the file is missing or unreadable, when no variant matches, or when a job is running. Throws EdiabasNetException for errors inside the identification job.
void ExecuteJob(string jobName)
Runs the named job in the current ECU file with the current arguments and publishes a new ResultSets list. Clears the four argument properties when it returns, so set them again before each job. Throws EdiabasNetException for ECU and interpreter errors, including EDIABAS_SYS_0008 for an unknown job. Throws ArgumentOutOfRangeException when a job is already running or the ECU file can't be opened. Rethrows transport exceptions unchanged. See Exceptions that aren't EDIABAS errors.
bool IsJobExisting(string jobName)
Returns true when the open ECU file defines the job. The library opens the file on the first ExecuteJob, not in ResolveSgbdFile, so the method returns false before that.
void CloseSgbd()
Marks the ECU file for closing. The library runs the exit job and closes the file at the start of the next ExecuteJob, or in Dispose.
void ClearGroupMapping()
Forgets cached group-to-variant resolutions so the next ResolveSgbdFile identifies the ECU again.
UInt32 GetFileType(string fileName)
Reads the type field from the file header. The value is 0 for a group file and nonzero for an ECU file. Throws ArgumentOutOfRangeException when the file is missing or unreadable.
List<List<string>> GetTableLines(string tableName)
Returns the rows of a table defined in the current ECU file. The first row holds the column names.
List<string> GetTableColumn(List<List<string>> tableLines, string columnName)
Extracts one column from the result of GetTableLines.

Argument and result properties

string ArgString { get; set; }
Semicolon-separated job arguments. Shares one buffer with ArgBinary, so setting either property replaces the other.
byte[] ArgBinary { get; set; }
Binary job argument. After you set ArgString, this property returns the Windows-1252 bytes of that string.
string ArgStringStd { get; set; }, byte[] ArgBinaryStd { get; set; }
Arguments for the standard jobs that the library runs automatically.
string ResultsRequests { get; set; }
Semicolon-separated result names to keep. An empty string requests every result. Names are stored upper-case. Don't assign null; the setter throws NullReferenceException.
Dictionary<string, bool> ResultsRequestDict { get; }
The parsed form of ResultsRequests.
List<Dictionary<string, ResultData>> ResultSets { get; }
Results of the last job. Index 0 is the system set. See Result set layout. Each job publishes a new list, so a list that you already hold doesn't change. The property is null before the first job and while a job runs.
bool NoInitForVJobs { get; set; }
When true, virtual jobs such as _JOBS, _TABLES, and _VERSIONINFO run without the initialization job.

State properties

string SgbdFileName { get; set; }
The ECU file to execute. Set by ResolveSgbdFile. Changing it schedules a file reload before the next job.
string GroupName { get; }, string FamilyName { get; }
The base name of the group file that you passed to ResolveSgbdFile, and the FAMILIE result of its identification job. Both are empty when you resolve a .PRG file directly.
string EcuPath { get; }
Directory that contains the ECU files. To change it, call SetConfigProperty("EcuPath", path).
EdInterfaceBase EdInterfaceClass { get; set; }
The interface handler. The setter links the handler to this instance and sets the Interface and IfhVersion properties. Cannot be changed while a job runs.
bool JobRunning { get; }
true while ExecuteJob runs, and while ResolveSgbdFile runs the identification job of a group file.
bool IsDisposed { get; }, bool Unloading { get; }
Lifecycle flags. Unloading becomes true when you call SetConfigProperty("EDIABASUnload", "1"). The Bluetooth and Wi-Fi transports then close their connection on disconnect, even when ObdKeepConnectionOpen is set.
ErrorCodes ErrorCodeLast { get; }
The code of the last error that RaiseError raised. Reset to EDIABAS_ERR_NONE at the start of each job. An error that the job masks doesn't change it.
bool Simulation { get; }, string SimulationPath { get; }
Simulation mode state and directory. To change them, call SetConfigProperty. See Simulation mode.
string IniFileName { get; }
Path of the EDIABAS.INI that the constructor found, or an empty string.
long TimeMeas { get; set; }
Accumulated transmit time in ticks. Shared across instances in the current implementation.
int InfoProgressPercent { get; }, string InfoProgressText { get; }
Progress values set by the running job. Read them from ProgressJobFunc.
string LogInfo { get; set; }
A free-text line that the library writes into the header of a newly opened interface trace file. Set it before the library writes the first trace line.
bool EnableFileNameEncoding { get; set; }
Enables the file name obfuscation scheme used by the Android app for ECU files.

Callback properties

AbortJobDelegate AbortJobFunc { get; set; }
bool AbortJobDelegate(). Return true to abort the running job.
ProgressJobDelegate ProgressJobFunc { get; set; }
void ProgressJobDelegate(EdiabasNet ediabas). Called on progress updates.
ErrorRaisedDelegate ErrorRaisedFunc { get; set; }
void ErrorRaisedDelegate(ErrorCodes error). Called before an error is thrown.

Configuration methods

string GetConfigProperty(string name)
Returns the property value or null. Names are case-insensitive.
string GetConfigProperty(string name, CallSource callSource)
Same as above. Pass CallSource.EdiabasOperation when an ECU file requests the property; some properties, such as Simulation, are hidden from ECU files unless SimulationCompat is set.
void SetConfigProperty(string name, string value)
Sets a property, or removes it when value is null or empty. Trace properties take effect immediately. An interface handler reads its properties when you assign it to EdInterfaceClass, so set them before that. See When properties take effect. The method does nothing after Dispose, and it ignores the trace properties when LockTrace is active.
bool ReadIniSettings(string iniFile, ref List<string> logList)
Reads the supported keys from an EDIABAS.INI file.
void ReadAllSettingsProperties(XmlDocument xdocConfig, ref List<string> logList)
Imports every appSettings entry from an XML document.

Error methods

void SetError(ErrorCodes error, Dictionary<string, object> args = null, [CallerMemberName] string source = null)
Records an error and raises it unless the job masked it. Interface handlers call this method. The compiler fills in source with the name of the calling member.
void RaiseError(ErrorCodes error, Dictionary<string, object> args = null, string source = null)
Stores the code in ErrorCodeLast, invokes ErrorRaisedFunc, and throws EdiabasNetException.
static string GetErrorDescription(ErrorCodes errorCode)
Returns the EDIABAS text for a code, for example SYS-0002: ECU OBJECT FILE NOT FOUND. Returns an empty string for an unknown code.

Logging methods

void LogFormat(EdLogLevel logLevel, string format, params object[] args)
Formats and writes a line to the interface trace, ifh.trc, when logLevel is at or below the configured IfhTrace.
void LogString(EdLogLevel logLevel, string info)
Writes a preformatted line.
void LogData(EdLogLevel logLevel, byte[] data, int offset, int length, string info)
Writes a hex dump of a telegram with a label.

EdiabasNet.ResultData

One result value inside a result set.

ResultType ResType { get; }
The declared type of the value.
string Name { get; }
The result name as the job wrote it. The dictionary key of the result set is the upper-case form of this name.
object OpData { get; }
The boxed value: Int64 for integer types, Double for TypeR, string for TypeS, byte[] for TypeY.

FormatResult

static string FormatResult(ResultData resultData, string format)
Converts a result to text with an EDIABAS format string. Pass an empty string for the default text conversion. The format has the form [-][width][.precision][e|E]<type> where type is one of C, B, I, W, L, D, R, T, or X (hexadecimal). For example, -8.2R prints a left-aligned real with two decimals in a field of eight characters. Returns null when the value can't be converted, which includes binary (TypeY) results with an empty format.
